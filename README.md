# Wishing List

A tiny single-file wish list demo — pure HTML, CSS and JavaScript, no build step, no dependencies.

Open `index.html` in any browser, type a wish, and add it to the list.

## How it works

- `addWish()` reads the input, appends the wish to the list and clears the field
- Minimal inline styles keep the whole thing to one file

## Run locally

```bash
# serve it with anything you like, or just open the file directly
npx serve .
```
